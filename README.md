AI-Based Ayurvedic Herbal Knowledge and Recommendation System

About the Project

This project uses Artificial Intelligence to identify medicinal plants from uploaded images and provide basic Ayurvedic herbal knowledge.

Features

- Medicinal plant image classification
- Plant prediction with confidence score
- Scientific and common plant names
- Traditional uses and herbal information
- Web interface built using Streamlit
- API developed using FastAPI

Technologies Used

- Python
- TensorFlow and MobileNetV2
- Streamlit
- FastAPI
- Pandas
- Pillow

How to Use

1. Open the web application.
2. Upload an image of a medicinal plant.
3. Click Predict Plant.
4. View the predicted plant name and available herbal information.

Disclaimer

AI predictions may be incorrect and should not be treated as confirmed plant identification or medical advice. Consult qualified experts before using any herb medicinally.

Project Status
